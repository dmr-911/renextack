The boring parts, done properly

Every pattern is used for real in a working example app, and covered by tests you can run.

Authentication

Email and password sign-up, password reset, session management and account deletion with Better Auth, all stored in your own database.

Server-side authorization

User and admin roles, ownership checks in every service, and tests that try to read other users' data.

Typed Postgres

Drizzle ORM, committed SQL migrations, an idempotent seed, and pooled connections that work on serverless.

A real API

Versioned REST endpoints with validation, one error format, pagination, search and per-user rate limits.

Accessible UI kit

Buttons, forms, modals, menus, tables and more, with keyboard support, light and dark themes, and design tokens.

Production defaults

Env validation, structured logs with secret redaction, security headers, a health check, Docker and CI.

Caching you can reason about

A worked per-user cache example with tag invalidation from both Server Actions and the API.

Optional integrations

Stripe, Resend, PostHog, Anthropic and file storage adapters, off by default, behind small interfaces.

Questions

Do I need any paid service to start?

No. Everything runs locally with Docker Postgres and console email. In production you need a database and a host, both of which have free tiers.

Is it locked to Vercel?

No. It deploys to Vercel with the included workflow, or anywhere that runs a Docker container or Node.js.

How is this different from a free template?

It's a working product with tests, not a collection of pages. Authorization is enforced on the server and tested, errors and validation are consistent, and the guides explain the trade-offs so you can change them with confidence.

Can I use it for client work?

Yes, with the Agency license. You can't resell the kit itself as a template.

What happens after my update period ends?

You keep every version you received, forever. Renew if you want newer releases.
